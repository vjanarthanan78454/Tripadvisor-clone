# Tripadvisor Clone

This is a simple **Tripadvisor Clone Website** created using basic HTML and CSS. The project is inspired by the Tripadvisor website and focuses on building a clean and attractive travel website.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation bar
- Search bar
- Popular travel destinations
- Hotel and restaurant sections
- Images and cards
- Simple and responsive design

## How to Run
1. Download the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## About the Project
I created this project to practice my HTML and CSS skills and improve my understanding of webpage layouts and styling.

**Note:** This is a frontend-only project created for learning purposes.
